# 心晴 MoodNest · 情绪小院

在线体验：https://bubble0421.github.io/moodnest/ （首页点「先逛逛示例小院」可看完整三周的示例）

**说不清也能记录 → 每条记录在像素小院里长成一株植物 → 陪你做一件适合当下的小事 → 回看时每条观察都有依据**

- 🏡 **我的小院**：像素花园是主场景。天空里飘着情绪气泡，小猫“小晴”会散步、打盹、偶尔说一句话。点植物回看那天的日记，点小物回看那次关怀。“布置小院”模式下才能拖动。
- 🫧 **记录**：12 种日常说法（“脑子停不下来”“心里堵堵的”“说不清”……），可以多选；情境标签是中性的，按常用程度排序；只选一个气泡就能「种下此刻」。
- 🧘 **关怀工具箱**：先问“有多少时间 × 现在愿意做什么”，再推荐一个行动（开始 / 换一个 / 自己挑）。三大类：自然声音（实时合成、定时、播放状态）、轻活动（可暂停、提前结束）、引导书写（可保存或放弃）。结束后的反馈只用来调整推荐顺序；小物奖励和好不好转无关。
- 📔 **情绪手记**：记录列表 + 回顾。回顾先给温柔的小结（记录了什么 / 可能重复出现的情境 / 有帮助的行动），措辞会随样本量调整，每条都能“查看这 N 条记录”或标记“不太符合”；图表不打分，不把没记录的日子当成零分。
- 🔒 数据只存在本机浏览器；默认使用本地规则，可以自行接入 DeepSeek / OpenAI 兼容接口 / Claude，页面会标明每段内容的来源，以及会发送哪些内容。
- 🤝 识别到高风险表达时，会显示心理援助热线。

像素素材全部为原创的字符画，运行时绘制；声音用 Web Audio 实时合成，不引用任何外部资源。
